📝 Comentario explicativo para el código



/**
 * Pokédex Interactiva - Proyecto Educativo
 * 
 * Descripción:
 * Esta página web permite explorar información de los primeros 100 Pokémon
 * utilizando la PokeAPI. Ofrece funcionalidades como búsqueda por nombre,
 * autocompletado, filtrado por tipo, visualización de detalles (altura, peso,
 * ID, tipos, habilidades, estadísticas) y evoluciones mediante un modal interactivo.
 * La galería incluye lazy loading de imágenes y placeholders para mejorar la experiencia
 * de usuario ante imágenes faltantes o lentitud de la API.
 * 
 * Tecnologías utilizadas:
 * - HTML5: Estructura semántica de la página, encabezados, botones y galería.
 * - CSS3: Estilos, diseño responsivo, gradientes, badges para tipos y modal visualmente atractivo.
 * - JavaScript (ES6+):
 *   - Fetch API: Para consumir los datos de la PokeAPI.
 *   - Funciones asíncronas y Promise.all: Para cargar detalles de los Pokémon eficientemente.
 *   - DOM Manipulation: Para generar la galería, filtros y modal dinámicamente.
 *   - Lazy Loading: Mejora la performance cargando imágenes solo cuando son visibles.
 *   - Eventos: Búsqueda, autocompletado, botones de filtro y modal.
 * - PokeAPI: Fuente oficial de datos y sprites de Pokémon.
 * - Placeholder Image Service: Para sprites faltantes o errores de carga.
 * 
 * Finalidad:
 * - Educativo: Permite aprender sobre JavaScript, consumo de APIs, manejo de datos dinámicos
 *   y diseño de interfaces interactivas.
 * - Interactividad: Desarrolla habilidades en filtrado, búsqueda y visualización de información
 *   de manera dinámica.
 * - Proyecto práctico: Combina front-end y manejo de APIs públicas, mostrando un caso real
 *   de desarrollo web moderno.
 * - Exploración Pokémon: Los usuarios pueden conocer detalles de cada Pokémon, sus tipos y
 *   evoluciones de manera visual y entretenida.
 */
